# tests/

Node checks with no dependencies. Each suite `require`s `engine/core.js`, and the app suites boot `engine/app.html` in a fake DOM. Run commands and expected counts: CLAUDE.md "Commands". Sibling packs are read from `../<lang>/pack` beside this repo; a missing sibling prints a NOTE and skips that part.

| file | what it boots / checks |
|---|---|
| engine_checks.js | core.js and app.html against the real packs/zh plus inline synthetic packs; build.sh output and the dist/zh.html + sw.js stale guard; tools/check_site.sh. |
| flagoff_snapshot.js | Flag-off golden harness (docs/HSK_MERGE.md §6): pack sources, `defaultProg`/`normalizeProg`/plan builders under a seeded RNG, and a fake-DOM boot of every tab for 3 seeds. Packs: zh, ../italian, ../korean, ../japanese (boot and pure goldens); source goldens also for spanish, french, german, russian, persian, indonesian. Goldens: golden/. |
| pron_aids_checks.js | Pronunciation aids (tones, typed reading, word taps, Sounds reference); control byte-identical to pinned engine sha 55c843e. Uses ../korean for one guard. |
| migration_checks.js | `migrateLegacy` (hsk_pinyin -> vocab_zh) and tools/diff_hsk_migration.js on synthetic hsk records of every version; cross-checks against ../chinese when present. |
| characters_checks.js | Characters stage logic on tests/fixtures/chars_packs.js; flag-off proof against pinned sha ee67120; pronFirst display rules; ../japanese when present. |
| characters_app_checks.js | Characters stage in app.html: path strip, unit Learn, item renderers, Test/Progress rows, legacy import, passage ruby, pronFirst, memory hints (teach cards, reveals and the written word's popover only, never a stimulus), word `say` carriers spoken and never shown; zh and ../japanese. |
| script_checks.js | Script primer logic on tests/fixtures/script_packs.js (ko-like, fa-like, ja-like). |
| script_app_checks.js | Script primer in app.html: choice card, Learn, Review, Script tab, no-voice path, RTL audit, 390px layout. |
| audio_checks.js | Recorded audio: core.js clip lookup, app call sites and fallback order, build.sh audio version, sw.js audio cache. App part boots ../persian. |
| passage_audio_checks.js | Passage questions spoken with Replay, source sentence on reveal, hidden question translation. |
| listen_mode_checks.js | Listening pass on spaced re-reads; no-voice control byte-identical to pinned sha ea5dcbc. |
| session_resume_checks.js | Session resume on zh: core key/fingerprint/staleness rules; reload mid-drill (same item, option order, queue, counts), tab switch and back, stale records dropped with no answer lost, Test and Words-tab drills, a typed item's choice counterpart, the Read flow and Today Read stage, storage keys, the build id on the built page (dist/zh.html), record size under 20 KB, a results screen across voiceschanged and render(), a hear item resumed before its voice is listed, [12] every exit/return path: a new browsing context (localStorage only), page hidden and shown, one parked session per app tab (Today, Test, Words, Read), tab re-tap / Escape / ‹ passages then Resume, fingerprints across answer and housekeeping saves, a second tab, import. |
| day_sim_checks.js | `pack.dayAware` on zh: plays 8 Today sessions in one simulated day (seeded mid-course progress, 85% right) with the flag off (control numbers) and on (thresholds): same-kind repeats of items right earlier that day, misses that never come back, due weak / mastered-unseen units never drilled, plan sizes, new material per session; character units at streak 3–5 reached; sessions 1–4 one evening and 5–8 the next morning: every miss back in a settling kind across midnight, no same-kind repeat of an item right that day or in the previous 2 sessions, `prog.sn` one per Today session; 14 one-session days: the 60 longest-unseen mastered units and every streak 3–5 unit drilled, no same-kind repeat within 2 sessions; Test and Words-tab planners after the day; day log, tiers, kinds, determinism; reload, tab away and back, "Resume today" and Test "Resume drill" never count a session (`prog.sn`, `day.n`). `--why` breaks repeats down by stage. |
| help_close_checks.js | `pack.helpClose` on zh: core flag, validator, passage and sentence word popovers and the audio toast (close button, tap outside, Escape, 8 s / 3.5 s timer held by pointer or finger, one at a time), flag-off markup unchanged; Read question order (options, verdict, Next, then passage toggle and passage) and the answer scroll with the passage open. |
| typed_from_checks.js | `pack.typedFrom` / `pack.glossFocus`: kind rotation and fallback, typed-meaning matcher and gloss formatter tables, stimulus leak checks and renderer on zh, every glossFocus render site; fix-round rules (reading notes off stimuli + 1193-gloss audit, truncated/lone-letter/"A or B" matcher rules, qualifier placement, characters -> pinyin choice fallback); control byte-identical to pinned engine sha ef44c6e with both fields absent. |
| validate_pack_audio_checks.js | tools/validate_pack.py rules for `pack.audio` and clip fields. |
| validate_pack_characters_checks.js | validate_pack/jsonify/build.sh handling of characters.json, ruby, legacy.json, words/units `say`. |
| validate_pack_script_checks.js | validate_pack/jsonify/build.sh handling of script.json. |
| validate_pack_spans_checks.js | tools/validate_pack.py rules for sentences.json `spans` and the pack-level coverage warning. |
| sentence_spans_checks.js | Flag-off control for sentence `spans`: core locate/gap/highlight/examples/passageSegments identical to pinned sha 8ad46d6 on zh (full) and every sibling pack (sampled). |
| fixtures/chars_packs.js | Synthetic zh-like and ja-like packs with deliberate hazards. |
| fixtures/script_packs.js | Synthetic ko-like, fa-like, ja-like primer packs. |
| fixtures/rtl_audit.js | RTL markup audit shared by engine, script_app and characters_app checks. |
| golden/ | Generated by `flagoff_snapshot.js --capture`: boot_<pack>_seed<n>.json, flagoff_pack_<pack>.json, pure_<pack>.json. Never hand-edit. |
