# tools/

Build-time helpers for packs and sites. Language repos call them as `engine/tools/...`. Commands: CLAUDE.md "Commands".

| file | label |
|---|---|
| jsonify_pack.py | Generator: a pack's `*.json` -> `*.js` consts that build.sh inlines. Run after every pack JSON edit. |
| validate_pack.py | Gate: schema and referential integrity against docs/PACK_SCHEMA.md; fails when the `.js` files are stale. |
| round/ | Republish-round scripts: `calibrate_queue.sh` (ETA calibration + gate queue, one background job), `republish.sh` (mechanical per-site republish, never pushes), pack diff guard; see tools/round/README.md. |
| check_site.sh | Stale-build guard for a language repo: rebuilds into a private temp dir, compares index.html and sw.js, checks both are committed. One line in each language repo's check.sh: `sh engine/tools/check_site.sh pack`. |
| pack_from_hsk.py | One-off, reproducible converter from the hsk (now ../chinese) data to packs/zh, incl. characters.json (with `hint` from zh_hints.json), legacy.json and attribution.json, plus patterns.json and docs/ZH_PATTERNS.md (every pattern with note and sentences, blanks in brackets) from the chinese repo's data/hsk_patterns.js when present. Idempotent. |
| zh_hints.py | Generator: tools/zh_hints.json, one character memory hint (or null) per distinct character of the hsk vocabulary (`[HSK_REPO_DIR]`, default ../chinese, the input pack_from_hsk.py reads), by template from Make Me a Hanzi dictionary.txt (pinned commit + sha256; `--fetch` downloads it into .cache/makemeahanzi/); tools/zh_hints_overrides.json (no cap, each with a reason and a source) wins over the templates; it also writes tools/zh_hint_meanings.json, the per-character meaning (pack gloss first sense, else the source's; `_meanings` overrides keyed by character or by `compound:char` for the sense in one compound) that pack_from_hsk.py puts in the `hint` of every unit of two or more characters, followed by ": <breakdown>" from tools/zh_hint_parts.json (the breakdown without its meaning) for a character that has no one-character unit. The JSONs are committed, so pack_from_hsk.py rebuilds without the network; run zh_hints.py first when the vocabulary gains characters (pack_from_hsk.py fails on a stale table). |
| zh_freq.py | Generator: tools/zh_freq.json, the wordfreq 3.1.1 zipf (`zh`) of every hsk word's written form (`.venv/bin/python tools/zh_freq.py [HSK_REPO_DIR]`; `--check` fails when the table is stale). Committed, so pack_from_hsk.py needs no wordfreq install; pack_from_hsk.py fails on a word missing from it. |
| zh_tiers_overrides.json | Owner-facing frequency-tier overrides (word -> ambient / core / peripheral), read by pack_from_hsk.py after the zipf rule; edit and regenerate to move a word (docs/ZH_TIERS.md lists them). |
| zh_freq.json | zipf per zh word, read by pack_from_hsk.py for `ft` tiers and each level's frequency order (docs/PACK_SCHEMA.md "freqTiers"). |
| zh_say_scan.py | Dev-only (needs pypinyin + jieba in a venv outside the repo): finds zh words a TTS may misread through a polyphonic character and writes the carrier table tools/zh_say.json + docs/ZH_SAY.md; without --write, exits 1 when they are stale. |
| zh_say.json | Word -> TTS carrier (`say`) map that pack_from_hsk.py copies into packs/zh words and units. Generated by zh_say_scan.py. |
| zh_gloss.js | Run by pack_from_hsk.py: applies zh_gloss_overrides.json to the hsk glosses and writes words `syn`, `typedSyn`, `noTypedMeaning` and `pronInGloss` from the engine's own typed-meaning keys (core.js `glossAltKeys`); fails on a fully covered stimulus that does not accept the covering word, on an override that spells its reading, and on a zh_gloss_expect.json answer the gloss rejects; report docs/ZH_GLOSS.md. |
| zh_gloss_overrides.json | Reviewed zh gloss rewrites (CC-CEDICT wording, each with `src` and the hsk text it replaces), synonym groups the keys miss, reviewed typed-answer rejects (`notTyped`), and noTypedMeaning add/remove. |
| zh_gloss_expect.json | The answers a B1 learner types for each zh word (every HSK 1-3 word with a typed meaning, most HSK 4); zh_gloss.js fails the build when the word's gloss rejects one. |
| diff_hsk_migration.js | Acceptance evidence for the hsk_pinyin -> vocab_zh migration: migrates an hsk export and prints per-record counts and totals (docs/HSK_MERGE.md §4). |
| tts_probe.html | Dev-only, self-contained, no-network TTS probe for the script primer (docs/SCRIPT_PRIMER.md §5, brief S0): ear-check which browser voices can say the primer units. |
| packbuilder/ | Shared corpus-based pack builder for language repos. See its README.md; hook reference in docs/PACKBUILDER_HOOKS.md. |

Language repos add their own `tools/` (build_pack.py shim, gloss_overrides.json, forced_a1.txt, bad_sentences.txt, id_map_v1.json, passages_src.json, REPORT.md); the contract is in packbuilder/README.md "Language repo contract".
